--- layout: base --- {%- comment -%} folino's home page, built around the title's three verbs: a section each for read, listen and write, then sharing, price, the FAQ excerpt and the download. Words come from _data/home.yml; the FAQ excerpt is the `featured` entries of _data/faq.yml. A language whose copy has no `read` yet still gets the earlier page, which follows the App Store description's order - separate annotate and edit sections, and a formats section at the end; the read section, the single write section and the export list under sharing appear only where their copy exists. The first feature section, whichever it is, carries the `features` anchor the header links to. The sections after the hero alternate plain and band, and a band's screenshot sits on the left. `n` counts the sections as they are written out, so the alternation holds whichever of them a language has. {%- endcomment -%} {%- comment -%} This layout renders before base.html, so it assigns the same `t` base.html does. {%- endcomment -%} {%- assign t = site.data.i18n[page.locale] -%} {%- assign fh = site.data.home[page.locale] -%} {%- include locale-url.html code=page.locale kind='faq' -%} {%- assign faq_url = locale_url | relative_url -%} {%- assign n = 0 -%}
