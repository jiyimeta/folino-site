{%- comment -%} Sets `locale_url` to a page in the language `include.code`: the page of kind `include.kind`, or of this page's kind when none is given. The home page is / in English - the store listings' marketing URL needs no language in it - and // otherwise; the FAQ is /faq//, the privacy policy /privacy-policy// and the Terms of Use /terms// in every language, English included. The Terms exist only in `terms_locales` (_data/folino.yml), so a caller outside those passes `en`. {%- endcomment -%} {%- assign locale_kind = include.kind | default: page.kind -%} {%- if locale_kind == 'faq' -%} {%- assign locale_url = '/faq/' | append: include.code | append: '/' -%} {%- elsif locale_kind == 'privacy' -%} {%- assign locale_url = '/privacy-policy/' | append: include.code | append: '/' -%} {%- elsif locale_kind == 'terms' -%} {%- assign locale_url = '/terms/' | append: include.code | append: '/' -%} {%- elsif include.code == 'en' -%} {%- assign locale_url = '/' -%} {%- else -%} {%- assign locale_url = '/' | append: include.code | append: '/' -%} {%- endif -%}
